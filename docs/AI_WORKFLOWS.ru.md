# AI автоматизации и повторяемые сценарии

Настройка задачи, проверка результата и сохранение сценария для повторного запуска без модели. Ниже — быстрый старт, ограничения и интеграции.

## Быстрый старт

1. Настройки → AI: включить ассистента, указать URL и модель провайдера с API Chat Completions. Проверить введённые настройки и сохранить.
2. Открыть **AI workspace** в боковом меню → **Try a demo**. Создаются отдельный локальный профиль и тестовый каталог на localhost. Запросов к модели пока нет.
3. Явно запустить предложенную задачу кнопкой **Start task**. Проверить таблицу и источник, выгрузить JSON или CSV. Журнал и количество запросов/токенов — в **Activity & details**, ограничения и разрешения — в **Options**.
4. Нажать **Create scenario → Add input**. Указать имя переменной `catalog_url` и точный URL демо отдельными полями, затем **Check read-only replay**. Редактировать JSON не нужно. Повтор работает через движок сценариев без модели; проверяются непустой результат и названия столбцов, а не достоверность данных.
5. Задать имя сценария и нажать **Save & open editor**. Открыть **Tasks**, выбрать сохранённый сценарий и профиль, заполнить `catalog_url`, добавить задачу в очередь и явно возобновить **Runs**. Альтернатива — задать параметры в переменных профиля и запускать через Scenarios → Runs. Для своего сайта проверить селекторы. Демо-адрес временный: после закрытия приложения недоступен.

Шаблоны: HTML-таблица → JSON; одна страница → текст; заполнение одного поля без отправки формы. Автосохранение сайта всё равно может сработать при заполнении.

## Пакетный запуск CSV

В **Tasks** выберите задачу с параметрами → **Run from CSV**. Укажите запятую или точку с запятой, сохраните **CSV template**, заполните строки и импортируйте файл. Поддерживается UTF-8, включая BOM; максимум 200 строк / 1 МиБ. Все строки проверяются до постановки в очередь. Одинаковые строки отмечаются; пропускаются только по явному выбору.

Каждая строка — отдельный запуск, последовательно на выбранном профиле. Очередь нужно возобновить в **Runs**. Ошибка строки не останавливает остальные; автоматических повторов нет. Ручной повтор сохраняет исходные параметры. Статусы последнего пакета доступны в Tasks после очистки очереди, в пределах общей истории 500 запусков.

Действия **Write file** сохраняют результаты в отдельные `outputs/batches/<batch-id>/<job-id>/`, включая ручные повторы. Python-код, общие переменные, скачивания и изменения сайтов не изолируются. Артефакты браузера находятся в деталях запуска. Параметры хранятся в локальной очереди, не в настройках профиля; не импортируйте секреты.

## Управление

- Начальный URL, ограничение текущим хостом, явное разрешение локальных файлов, подтверждения действий, пауза, остановка и вопросы оператору.
- Пауза — между действиями. Остановка сохраняет завершённые шаги; прерванное действие могло уже изменить страницу. Повторять отправку формы автоматически нельзя.
- «Успех» от модели не означает проверенный сценарий. Автопроверка повторяет только чтение/извлечение. Интерактивные сценарии проверяются вручную через Runs.
- Таблицы: уникальные непустые заголовки, одинаковая ширина строк, максимум 200 строк/30 колонок/1 МиБ. Объединённые ячейки не поддерживаются.
- Параметры заменяют точные записанные URL/значения полей. Недостающие переменные останавливают запуск. При экспорте workflow литеральные URL/поля запрещены; селекторы нужно проверить вручную.
- История: последние 100 записей, восстановление только в исходном workspace. Файлы результатов не удаляются автоматически.

## Приватность

Текст страницы, URL, подписи, задача, извлечённые данные и ответы оператора передаются выбранному провайдеру. Содержимое редактируемых полей не входит в снимки/извлечение; распознанные введённые пароли заменяются переменными и скрываются в журнале. Это не универсальное распознавание секретов: сайт может вывести токен обычным текстом или в URL. Не использовать чувствительные профили для демо и не вводить пароли в ответы оператору.

Локальный endpoint оставляет запросы модели на компьютере, но браузер продолжает обращаться к сайтам. Ключ провайдера хранится в существующих локальных настройках; артефакты и переменные профиля могут содержать чувствительные данные. Ограничение хостом не является сетевым фильтром. Полная анонимность не гарантируется.

## Интеграции и проверки

[Подробные команды CLI/MCP, пример n8n и проверки](AI_WORKFLOWS.md#local-cli).

CLI использует Python исходного проекта и существующую очередь; приложение нужно закрыть. Только локальный workspace и сценарии извлечения: без Python, HTTP-request, вложенных сценариев и интерактивных действий. Незавершённые задания не запускаются автоматически.

MCP — отдельная необязательная зависимость. По умолчанию только список и история; запуск — для явно разрешённой пары сценарий/профиль с фиксированным хешем. Отмена MCP-запроса не отменяет уже начатый локальный запуск; бюджет запуска — 120 секунд.

n8n JSON — неактивный пример для доверенного self-hosted Windows-инстанса на том же компьютере. Проверены импорт и выполнение в изолированном n8n 2.41.5; ваш deployment всё равно требует проверки. Подстановка внешнего текста в shell-команду запрещена.

Автотесты AI используют реальные браузеры и локальный тестовый endpoint, не платную модель. Они проверяют механику, но не качество рассуждений модели и не совместимость со всеми сайтами.

Дополнительно настроенная `deepseek-flash` прошла три реальных запуска на каждом движке и полный UI-поток до проверенного сохранённого сценария. Использовался только синтетический каталог, без личных профилей. [Отдельные команды реальной проверки](AI_WORKFLOWS.md#opt-in-real-provider-checks) обращаются к провайдеру и могут расходовать баланс API.
