# Проверка AI автоматизаций CamouFlow

## Реализовано

1. Исправлены настройки провайдера, первоначальный выбор профиля, ложный успешный клик и потеря завершённых шагов при остановке.
2. Добавлены начальный URL, ограничения навигации, подтверждения, вопросы оператору, пауза и остановка.
3. Реализованы извлечение таблиц/текста, источники, предпросмотр, JSON/CSV и история с восстановлением.
4. Добавлены параметры сценария, проверка повторного чтения и схемы результата, экспорт workflow, три шаблона и изолированное демо.
5. Реализованы локальный CLI на существующей очереди, блокировка одновременного доступа, ограниченный MCP на официальном SDK и неактивный пример n8n.
6. Подготовлены инструкции RU/EN, обновлён README и план запуска `LAUNCH_PLAN.md`.

## Подтверждено проверками

- 78 автоматических тестов прошли.
- Camoufox и CloakBrowser: реальный браузер → локальный тестовый HTTP-провайдер → таблица → параметризованный сценарий → повтор с другим URL/данными → JSON → запуск через CLI.
- Проверены исключение редактируемого содержимого, уникальность селекторов и чтение средней части длинной страницы после прокрутки.
- QML/bridge: первоначальный выбор профиля, изменение настроек, подтверждение действия, пауза, демо, шаблон, CSV, экспорт без исходного URL, реальный replay, восстановление истории и сохранение.
- Проверены межпроцессная блокировка workspace и отказ сохранения в другом workspace.
- MCP stdio: handshake, схемы инструментов, список/история, явный allowlist без аргументов запуска, реальное выполнение через CLI на обоих браузерах.
- Сборка v0.4.0 `dist/release-20261002-021103/CamouFlow/CamouFlow.exe`: свежие runtime-отчёты обоих движков содержат `passed: true`; упакованный AI QML совпадает с исходником.
- Компиляция, критические проверки Ruff, `git diff --check` и UTF-8 без BOM/повреждённых символов прошли. Полный legacy lint не объявляется чистым.

## Не подтверждено

Произвольные сайты, другие модели и изменение рабочих cloud-данных не проверялись. Автоматический replay ограничен чтением; интерактивные сценарии требуют явной проверки через Runs.

## Дополнительная проверка с разрешения владельца

- Версия подготовлена к v0.4.0; версия приложения и Windows resource синхронизированы.
- Настроенная `deepseek-flash`: 3/3 успешных запуска на Camoufox и 3/3 на CloakBrowser. Каждый запуск — два запроса, корректные три строки и повтор на изменённых данных без дополнительных запросов к модели.
- Полный UI-поток с реальной моделью: старт, данные, CSV, параметризация, replay и сохранение `_ai_replay_checked`. Ключ не копировался в тестовый workspace.
- Реальные PNG/GIF демо записаны в `images/ai-workflow-demo.*`; личные профили не использовались.
- n8n 2.41.5: импорт в отдельную временную БД, выполнение статической команды, реальный браузер, артефакт и успешный результат узла разбора JSON. Рабочий n8n не изменялся.
- Live cloud: успешно прочитаны auth context, профили и сценарии; рабочие данные не изменялись. Cloud-запуск/блокировки в этом тесте не проверялись.
- Документация: устранена ошибка истёкшего Retype, установлен 4.6.0, задан реальный Pages URL; 35 страниц собраны без ошибок/предупреждений.

Публикация v0.4.0 разрешена владельцем. Следующий продуктовый этап — пилот с целевыми пользователями; реальные пользовательские отзывы не имитировались.
