## Один менеджер, три движка

Постоянные профили, пулы прокси и запуски сценариев — локально. Опишите задачу AI,
проверьте записанные действия и повторяйте их без нового обращения к модели.
Для командных поручений и общей работы можно подключить наш hosted-сервис.

| Движок | Основа | Роль в CamouFlow |
| --- | --- | --- |
| Camoufox | Firefox-based, сторонний | Настраиваемые антидетект-профили через существующую интеграцию |
| CloakBrowser | Chromium-based, сторонний | Настраиваемые антидетект-профили через существующую интеграцию |
| **Glint** | **Наш публичный форк Chromium/Blink** | Windows runtime в разработке; нативные C++/Mojo-политики, не переименование чужого движка |

Настройки и возможности зависят от движка. Glint **ещё не production-антидетект**;
неподдерживаемые настройки не заменяются молча. Релиз приложения не означает,
что в нём есть последняя экспериментальная сборка Glint.

## Glint: что нативное, а что ещё разрабатывается

| Поверхность | Реализация | Текущая граница |
| --- | --- | --- |
| Идентичность профиля | Приватный версионируемый ключ; derivation по partition/surface на стороне браузера | Тесты ключей и контекстов прошли; полного генератора паспортов устройств пока нет |
| CPU / память | Нативные ограничения раскрываемых значений | Не произвольная эмуляция другого компьютера |
| Шрифты | Нативный выбор установленных Windows-шрифтов | Без выдуманного списка и симуляции шрифтов macOS/Linux |
| WebRTC | Нативная политика маршрутизации | Контролируемые проверки прошли; внешние утечки проверяются отдельно |
| Признаки автоматизации | Патчи отдельных automation/headless/CDP-сигналов | **Не полная невидимость CDP**; менеджер использует Playwright/CDP |
| Workers | Передача seed и управление запуском под developer-only флагом | Runtime-проверки прошли; точечные Blink handoff-тесты ещё не выполнены |
| Политика документа | Кандидаты browser → commit IPC → renderer → Document | Незарегистрированные черновики; runtime и восстановление при несовпадении partition не проверены |
| Canvas | Кандидаты нативной защиты чтения и экспорта | **Защита не включена**; baseline не доказывает защиту |
| WebGL / WebGPU / Audio | Запланированная нативная защита | Не завершена; произвольной эмуляции GPU и аудио нет |
| TLS / HTTP | Штатный Chromium/BoringSSL | Подмены ClientHello нет; сравнительные измерения впереди |
| Мобильные профили | Desktop Web Emulation: viewport/touch | **Не настоящий Android Chrome или iOS Safari**; полная мобильная идентичность не готова |
| Платформы | Проверенный Windows runtime в разработке | Проверки собственного runtime Linux/macOS отложены |

## Проверки Glint

Последний проверенный браузер: **Windows · Chromium 148.0.7778.96 · патчи 001–027**.
Это закреплённая экспериментальная база, не заявление об актуальности обновлений безопасности Chromium.

| Проверка | Результат | Что подтверждает |
| --- | --- | --- |
| Существующие runtime-политики | **160 проверок / 8 gates прошли** | Контролируемые локальные проверки, не оценки внешних детекторов |
| Запуск / перезапуск / отклонение workers | **40 проверок прошли** | Диагностический opt-in; не доказательство защиты Canvas |
| Canvas API baseline | **4 фазы прошли** | Поведение пикселей, экспорта и API без защиты |
| CreepJS / Pixelscan / BrowserScan / Sannysoft | **Не запускались для 001–027** | Результаты прошлых сборок не переносятся |
| Fingerprint Playground / IPhey / BrowserLeaks | **Не запускались для 001–027** | Проверки распознавания, согласованности и утечек впереди |
| Сравнение TLS / HTTP | **Не запускалось для 001–027** | Нужен stock Chromium на том же маршруте |
| reCAPTCHA / Turnstile с реальными ключами / hCaptcha | **Не подтверждены для 001–027** | Без обещаний баллов и гарантированного прохождения CAPTCHA |

[Живая матрица тестов](docs/GLINT_TEST_MATRIX.md) сохраняет историю сборок,
сервисы, ссылки на доказательства и ограничения. Число успешных проверок — не
процент готовности антидетекта и не гарантия доступа к сайтам.

## Возможности

### 🗂 Профили

- создание, редактирование, дублирование и удаление профилей
- запуск/остановка браузерной сессии профиля
- массовый импорт по шаблону разбора аккаунтов
- теги-группы и поиск по имени, тегу и прокси
- привязка прокси, переменные и cookies профиля
- настройки на профиль зависят от движка: locale, timezone, User-Agent, WebGL/GPU, CPU cores; ограничения Glint указаны выше
- пакетный запуск сценария на профилях с выбранным тегом

### 🕸 Прокси

- пулы/группы прокси: создание, переименование, удаление
- массовый импорт списков: `socks5://host:port:user:pass`, `http://user:pass@host:port`
- проверка здоровья: по одной, по пулу или все сразу — статус, задержка, гео
- карантин и освобождение прокси, снятие привязок
- статистика пула: активные, в проверке, упавшие, локации

### ⚙️ Сценарии

- визуальный редактор: перетаскиваемые шаги на холсте, pan/zoom
- связи между шагами `успех` / `ошибка`, контекстное меню узлов и связей
- библиотека сценариев: создание, дублирование, удаление
- запуск сценария на выбранном профиле, панель последних прогонов
- общие переменные внутри редактора, шаг-редактор с raw JSON
- маркетплейс сценариев (при подключённом сервере)

Поддерживаемые шаги: `start`/`end` · переход по URL · HTTP-запрос · ожидание элемента/загрузки · пауза · клик · ввод текста · запись/парсинг переменных · общие переменные · извлечение текста · запись в файл · условие `if` · работа с вкладками · тег · запуск другого сценария · лог/сообщение

### 🧬 Движок браузера

- переключение Camoufox ↔ CloakBrowser и раздельные настройки по движку
- режимы запуска: окно / headless / виртуальный дисплей
- гуманизация поведения: курсор, скорость мыши, задержки печати, пресеты
- пул ОС-отпечатков и seed для Camoufox, аргументы запуска Chromium
- переопределения navigator/UA/WebGL/CPU, window/screen размеры
- JSON-оверрайды (navigator, window), addons/шрифты, права и заголовки
- статус-панель движка: проверка совместимости и обновлений

### 📋 Журнал

- события приложения и автоматизации в таблице `уровень · время · событие`
- фильтры: все / ошибки / предупреждения с живыми счётчиками
- обновление и очистка журнала (с подтверждением)

## Архитектура

```text
┌─────────────────────────────┐        ┌─────────────────────────────┐
│  Desktop-приложение (репо)  │        │   Сервер (опционально)      │
│  PyQt6/QML + Python-ядро    │◄──────►│   команды · роли · пулы     │
│  Camoufox · CloakBrowser    │  API   │   аудит · маркет            │
│  локальные профили и данные │        │   веб-консоль владельца     │
└─────────────────────────────┘        └─────────────────────────────┘
```

Локальный режим полностью самодостаточен. Сервер подключается опционально — для командного доступа, общих пулов и маркетплейса сценариев. Сайт проекта: **[camouflow.site](https://camouflow.site)** (RU/EN).

```text
app/
  core/         интеграция с движками, отпечатки, прокси
  qml/          интерфейс (QML): страницы и компоненты
  services/     сценарный движок и исполняемые шаги
  storage/      локальная БД и хранилища
  ui/bridge/    Python ↔ QML мосты
images/         скриншоты для README
```

## Быстрый старт

**Готовая сборка для Windows:** [последний релиз (zip)](https://github.com/Tort1k558/Camouflow/releases/latest) — распакуйте и запустите `CamouFlow.exe` (движки браузера скачаются при первом запуске). Все версии и изменения: [Releases](https://github.com/Tort1k558/Camouflow/releases) · [CHANGELOG.md](CHANGELOG.md).

Или запуск из исходников. Требования: **Windows**, Python 3.12, Git.

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Первый запуск может занять время — скачиваются браузерные зависимости движков.

```bat
python main.py
```

### Сборка Windows-приложения

```bat
build.bat
```

Готовый билд: `dist\<build-id>\CamouFlow\CamouFlow.exe` (новая папка с датой и временем для каждой сборки).

## Данные и приватность

### Готовые задачи без редактора

Откройте **Tasks → Record a task**, выполните действия в браузере и остановите запись. Проверьте список действий и предупреждения, выберите изменяемые значения URL/текста/выбора, задайте понятные подписи и нажмите **Save task**. Одинаковые записанные значения заменяются одним общим параметром. Распознанные секретные поля остаются переменными профиля; технический JSON скрыт по умолчанию.

В **Tasks** выберите задачу и профиль, заполните параметры и нажмите **Queue task**. Запрос к модели не требуется. Используются существующая очередь, блокировки профилей и подтверждение Python-кода. Возобновите очередь в **Runs** явно и оставьте приложение открытым. Параметры сохраняются в локальной очереди, но не становятся значениями профиля по умолчанию: не вводите здесь пароли. Изменённую задачу нужно выбрать и проверить заново. **Run details** открывает результаты, ошибки и артефакты запуска. Предупреждения записи сохраняются вместе с задачей.

Все рабочие данные — профили, сценарии, прокси, настройки, журналы и браузерные профили — хранятся локально. Текущий каталог данных показан в **Settings → App Settings**.
